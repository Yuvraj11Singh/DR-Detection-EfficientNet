/ Pipeline

How the model
processes images.

A clinically-validated deep learning pipeline built on transfer learning from ImageNet weights.

01

Image Preprocessing

Images are resized to 224×224 pixels and normalized. EfficientNetB0 applies its built-in preprocessing scaling per pixel values.

02

Feature Extraction

EfficientNetB0 backbone (frozen then fine-tuned) extracts deep visual features from retinal vasculature, optic disc, and lesion patterns.

03

Severity Classification

A multi-class output neuron predicts DR probability across 5 stages, generating Grad-CAM heatmaps for model interpretability.

/ Architecture

Model performance
& architecture.

Fine-tuned EfficientNetB0 with two-phase training: frozen backbone + selective unfreezing of top 30 layers.

AUC Score

0.94+
Area under the ROC curve on APTOS validation split. Measures model's ability to discriminate between DR and non-DR cases.

Training Setup

  • Backbone
    EfficientNetB0 — ImageNet pretrained
  • Phase 1 LR
    1e-4 Adam — head training, 5 epochs
  • Phase 2 LR
    1e-5 Adam — fine-tune top 30 layers, 10 epochs
  • Regularization
    Dropout 0.4 before classification head
  • Input Size
    224 × 224 × 3 RGB
  • Dataset
    APTOS 2019 Blindness Detection
